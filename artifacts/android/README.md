## 安装

1. 将 APK 传到安卓手机或平板，从文件管理器打开并覆盖安装旧版；不要先卸载，按系统提示允许该来源安装。
2. 首次启动由家长设置密码，无默认密码。需要跨应用答题时授权「显示在其他应用上层」、通知和后台运行。
3. 先用 1 分钟间隔在家长陪同下验收，确认答题、密码退出、息屏恢复和题库导入正常。

这是带调试签名的兼容诊断测试包，不是应用商店正式发布包。后续在获得授权时读取到荣耀系统管家 force-stop 记录，确认进程与服务被终止；**没有通过可靠后台拦截验收，不能宣布已经解决或可以防退出**。普通原生入口与浮层都可能被系统限制，当前已停止设备访问。不要仅凭回到 App 或点击通知后出现题目判断成功；不要反复卸载重装排查。
