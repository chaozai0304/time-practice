# 题库、教材范围与知识游戏

## 教材范围：明确已实现与待校对内容

- 支持小学 1–6 年级、初一至初三、高一至高三，按学段组织科目；具体开课年级和学习进度以学校实际教材为准。
- 内置的是原创基础复习和生活应用题，不是北京官方考试题库，也不代表任何年级全部知识点。数学包含分年级生活场景、分数、方程、函数等基础例题；其他学科包含常识与基础概念复习。
- 三年级英语包含可导出的分类基础词/短语，每词生成“看英语选中文”和“看中文写英语”。**不是北京版、PEP 或外研某版三年级上下册的完整词表。**
- 尚未获得实际教材的出版社、版次、英语起始年级、上下册词表，官方课程页面提取也未取得可用正文；不能据此声明“所有北京要求已满足”或“教材词汇全部覆盖”。
- 完整对齐需要提供实际教材名称/版次与词表，按单元导入后逐项核对，保留 `source` 来源。家长自编/导入也不自动等于已由教材核验。
- 科目包含小学科学、道德与法治；初中历史、地理、生物、物理、化学；高中思想政治、信息技术、通用技术等，并保留音乐、美术、体育与健康、劳动。学段列表不是所有科目从该学段第一学年同时开课的声明。

## 三题型与导入

进入“我的题库”并验证家长密码：

1. “添加题目”选择年级、对应科目和 `选择题/填空题/判断题`。
2. 选择题填写 2–6 个不重复选项和完整答案文字；填空题不填选项；判断题直接选择“正确/错误”。
3. 填写单元和来源，可选择是否允许出现；保存后用筛选、答案详情和开关复查。
4. 下载 [三题型 CSV](../examples/questions.csv) / [JSON](../examples/questions.json)。示例含初中物理、高中化学、真假判断和停用案例。

题库字段：`grade,subject,type,prompt,options,answer,explanation,enabled,unit,source,word,semester,lesson,lessonTitle`。`type` 可为 `choice/fill/boolean` 或对应中文名称；旧文件缺少 `type` 时仍按选项推断选择/填空。CSV 选项用 `|` 分隔。判断答案支持 true/false、对/错等，导入后统一为“正确/错误”。

`grade` 支持 1–12 或“一年级…六年级/初一…初三/高一…高三”。7–9 为初中，10–12 为高中；`subject` 必须是当前学段的精确科目名。`enabled` 为 true/false，省略默认启用。每文件不超过 5 MB、每批 1–2000 题、本地最多 5000 题；错误整批拒绝并提示题号。

## 英语词表

使用专用“导入英语词表”，不是普通题库导入。模板：[CSV](../examples/vocabulary.csv) / [JSON](../examples/vocabulary.json)。

字段为 `english,chinese,grade,unit,semester,lesson,lessonTitle`；`grade` 省略默认三年级。英文可包含字母、空格、连字符和撇号；同年级/册次/课次的重复词条整批拒绝，同词可跨课程复习。每批 1–1000 词，自动生成至多 2000 道双向题，确认预览后合并；原题不被覆盖。大小写和规范化空格不影响英文判分，不支持同义词/多答案自动判断。

“导出基础词表”可取回应用当前的完整**基础词库**，用于按实际教材增删校对；“完整基础词库”不等于“完整教材词表”。

## 控制出现范围与智能复习

### 上下册、课次和在线编辑

`semester` 为 upper/上册、lower/下册或 unspecified/未标注；`lesson` 为第几课（1–300 整数或留空）；`lessonTitle` 是可检索课题。模板课号仅作格式示范，不证明官方进度；旧题缺失字段保留未标注，不猜归属。

在题库直接编辑内容、答案、年级、科目、上下册、课次和课题；改年级时保留合法科目，否则切到数学。保存保留原 ID 和记录，并定位到已编辑题，不自动改变孩子学习规则。所有操作仍保存本机，无新增云服务器。

每页 50 题，可组合筛选年级/科目/册次/课次/题型/单元/状态，关键词检索题干、课题和来源；逐题勾选或“全选筛选结果（含其他页）”。批量操作当前筛选或已选题；删除先家长验证，再核对清单并输入相同数量确认，取消不删除，历史保留。守护运行时禁更改。

- 按年级、科目、题型、单元、启用状态和关键词筛选。
- 单题开关或“启用/停用当前筛选”均需家长验证。守护运行中不允许改题库；已停用题不会进入网页、原生或游戏抽题池。
- 页面显示未练习、练习次数与错误次数。守护、独立练习与三款新知识游戏只取当前年级、所选科目中启用题；独立单词星际跑酷仍取当前年级启用英语拼写题。列表筛选只是管理视图，不额外改变学习规则。
- 权重：新题 8；已练习题 `1 + 错率×8 + 最近一次错误时3 + 间隔天数奖励（最多2）`；最近 5 次作答对应题权重乘 0.15。
- 按指数随机键加权、无放回排序，不保证所有新题绝对排在所有旧题前面，也不承诺永不重复。错题继续当前题，达标后用最新记录重排下一轮；可用题少于目标时循环。
- Android 开始守护时合并网页与原生历史并按记录 ID 去重，后续使用原生新增记录；只存本地，不采集其他应用内容。

## 单词星际跑酷

首页“进入单词星际跑酷”进入全屏射击。中文目标在游戏星空中出现并下落，最多同时 3 个不同英文词；点中文锁定，也可填写场上任何一个词的正确英文。

输入英文后按 Enter/点“发射子弹”：错误不发射并记录真实尝试；正确创建追踪子弹，子弹实际飞行、碰撞后才消除目标并增加命中数。飞行中不能重复击中同一目标；提示只给首字母/字符数，听写不自动填写或计分。漏词只增加游戏漏词数，不伪造作答；题量少时循环复习，命中 10 个后提示休息。

“调整难度”可设中文出现间隔 1–12 秒、下落速度 1–8（场景高度百分比/秒）；默认 4 秒、2.5。调节时暂停，参数自动保存本机并实时重算生成时间；不修改家长学习规则。暂停/后台/守护接管/退出停止循环，保留本轮目标、子弹和草稿；退出后重进开始新轮，历史和难度保留。减少动态效果取消装饰闪光，核心目标移动与子弹仍用于真实玩法。

游戏不会解除后台守护，守护/练习运行时首页游戏入口不可用。分数与航程仅是鼓励反馈，成长足迹来自实际作答；没有广告、联网排行榜、充值或真实暴力内容。

## 独立知识街机（1.7，替换1.6同构玩法）

保留原英语单词专项，三款知识游戏全部重构：雷霆空战是纵版自动连发飞机大战，弹珠破阵是挡板/球/砖块反弹物理，秘境跳跃是横向重力平台。三者有独立状态与胜负条件，不再共用下落敌人和追踪弹循环。各8关可选，过关保留能力，重试/选关重置本局；退出不保存游戏局面，但真实学习记录保留。

入口 → 大厅查看当前年级/科目/启用数量 → 进入选关 → 拖动战机、接球或跳跃 → 实际接触「?」知识补给（弹珠由挡板接住） → 游戏冻结出题 → 选择/填写并确认 → 正确才升级当前玩法能力。错误真实记录、保留题目与冻结状态；结束本局不奖励、不解除守护。无当前范围题禁进入，不调用范围外题兜底。

题目支持选择/填空/判断，保留册次课次标签。数学/语文/英语等当前可用科目按已领取次数轮换，科目内沿用新题/错题加权和近期降权；禁用、其他年级或未选科目不会出现。听写不填答案、不计分；没有本地语音继续文字作答。

空战自动连续发射直线弹，无需按住发射；拖动/WASD/方向按钮移动，空格/炸弹键消除弹幕，炸弹次数有限。升级双发、三/五向、重型弹、僚机，敌机分编队和型号，敌方瞄准弹与Boss扇形弹幕都可造成受击；生命有短暂无敌期。必须实际击败Boss才能过关，不按击破数量直接放行。

弹珠左右移动挡板，发球后根据实际反弹角度消砖；球全掉才扣生命并回到发球。升级加宽挡板、多球、穿透；清空砖阵过关。没有战机、敌方弹幕或发射按钮。

平台左右移动、单次起跳、重力落地，避开沟壑与守卫，抵达旗帜过关；失败回最近落地检查点并扣生命。升级二段跳、滑翔、吸星与步伐，不复用空战武器。空中二段跳须松开再按，滑翔解锁后按住跳跃。支持方向与跳跃多点触控。

1.8平板触控：左侧十字/左右方向盘，右侧大动作键；空战可滑向斜向，战区采用相对拖动不瞬移，长按连续/短点微调。平台移动与跳跃独立持有指针，松开一指不清掉另一指。弹珠增加底部大滑条，避免挡住球台；键盘与触控统一合并，斜向归一化不超速。触摸取消、失焦、旋转、暂停、答题与选关清空输入，不改变游戏时钟或学习规则。横屏空战控件利用两侧空白，竖屏在底部分区；[横屏](screenshots/17-tablet-controls.png)/[竖屏](screenshots/18-tablet-portrait.png)为电脑视口，非真机验收。

各玩法6级能力，正确回答加100分并恢复1生命（上限5），满级仍可答题补给；记录不是装饰分数，也不虚构未输入的作答。关卡最后一关完成显示胜利。

新街机采用原创Canvas 2D素材、分层卷动、金属机身、连续弹流、粒子爆炸、霓虹球台和森林浮岛；不冒称3D或复刻任何既有游戏的专有美术。无需远程素材或WebGL，Canvas不可用则明确提示，不能伪装已渲染。暂停、后台、守护接管停止游戏与语音，答题保留同画布。原学习小岛与宇宙答题背景继续采用Remotion/Three.js。截图见 [大厅](screenshots/12-game-hub.png) 和 [道具题](screenshots/16-pickup-question.png)，为隔离电脑证据，不代表设备/厂商后台验收。

## 旧数据升级

课程字段与独立 `gameSettings` 为可选扩展，不改存储版本或再次补库；原密码、规则、题 ID、启停状态、作答和守护进度保持原值。旧数据没有游戏难度时用默认值。

存储仍使用 `sprout.data.v1`。首次升级以 `contentRevision=2` 一次性追加原创基础题，保留原题 ID、家长密码、作答历史、停用状态、当前题序、截止时间与答题进度；不覆盖旧题，满容量不追加。家长之后删除/停用的新题不会在每次启动时重新添加。请定期由家长导出备份，不卸载或清空真实数据。

## 英语听写与安装更新

英语拼写题和游戏提供“听英文（听写）/重听”，只读发音，不显示/填写答案、计分或开始下一轮；暂停、切题、家长页/后台及界面离开取消播放。Web/iOS WebView 用系统本地 SpeechSynthesis 英语语音，Android 原生用离线 TextToSpeech Voice；缺语音时降级，不下载、联网合成或申请麦克风。实际可听性取决于语音引擎、媒体音量和静音设置，虚拟回归只证明请求/降级/状态，不证明真机声音。

同包名同签名覆盖新版通常保留配置；先卸载、清数据或换浏览器存储会丢失。建议先导出备份。更新会结束旧进程，之后检查守护状态和权限、必要时恢复服务；保留数据不等于服务跨安装连续运行。本轮不替用户安装或操作设备。

## 验证边界

单测验证题型、导入、加权和非空旧数据迁移；浏览器验证应用内交互；Android JVM 验证原生策略与已有生命周期。它们不证明教材完整覆盖、荣耀后台拦截或真实设备输入/文件选择器可靠性。当前没有操作平板，iOS 没有可安装 IPA。
