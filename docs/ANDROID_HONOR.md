# 荣耀平板：安卓 1.2 兼容诊断版

用户重新安装后仍反馈：看小红书时到期不显示题目，返回应用才显示；家长密码页点击输入框、系统键盘出现后消失。上一版的 JVM/浏览器通过不能证明这些真机问题已解决。**后续在获得授权时读取荣耀 Android 14 系统记录，确认系统管家触发 force-stop，终止进程与服务；没有通过可靠后台拦截验收**，不能宣称后台拦截已修好。当前不再访问或操作平板。

## 已确认的强停边界

系统退出记录包含 `USER REQUESTED / FORCE STOP`，系统管家为触发来源，包状态为 `stopped=true` 和 `iAwareStopped=true`；此时前台服务不存在，虽然保存的守护标记仍可能为开启。悬浮窗和前台服务权限已允许，也不能阻止这种强停。普通前台服务和重启定时器不是系统级防退出方案。

临时改善由家长方便时自行操作：允许自启动、关联启动和后台活动，取消电池限制，若系统支持则锁定最近任务卡片。这只能降低被清理概率，不能保证孩子无法退出。Device Owner / DPC 多应用锁定尚未实现；安装 APK 或普通设备管理员不等于已启用强管控。后续激活必须另行授权，不应自行重置、移除账号或更改设备管理权限。

## 安装与授权

1. 直接安装 `artifacts/android/sprout-android-1.2-debug.apk` 覆盖旧版，不要先卸载，避免丢失本地题库、密码、记录和故障诊断。版本为 `1.2` / versionCode `3`，同包名、同调试签名。`sprout-android-debug.apk` 为同内容兼容文件名。
2. 家长进入设置，允许“显示在其他应用上层”和通知。
3. 在系统设置搜索“应用启动管理”→ 学伴时光，关闭自动管理；允许自启动、关联启动、后台活动。部分系统在应用详情或电池设置下。
4. 电池设置中将学伴时光设为不受限/不优化；如系统另有“后台弹出界面”，也需允许。入口与名称取决于 MagicOS 版本，应用不能静默授予这些权限。
5. 应用内“设备与权限”提供应用详情和电池优化入口，**不是一键自动授权**。

## 本次改动与边界

- 密码页新增页面内的 0–9、删除、清空按钮，密码输入控件不获得编辑焦点，也不唤起系统键盘；验证逻辑与限流不变。移除旧版 `onPause` 立即恢复遮罩的条件，只在页面真正 `onStop`/销毁时恢复，避免临时焦点变化让题目盖回密码页。这是代码中可确认的风险修正，不是在没有日志时断言荣耀的唯一根因。
- 原生后台到期时，除了原有浮层，还一次性尝试普通 `GuardQuizActivity` 答题入口；两种界面共用原生题目、答案验证和进度。普通页面进入前台后撤下浮层，答对达标后关闭页面并继续原服务。不会每秒反复拉起页面，也没有申请来电/闹钟全屏权限。
- 普通页面仍受系统/荣耀后台启动限制；请求成功不等于页面已显示，必须有 `quiz_activity_resumed` 确认。未确认则记录告警。保留通知“去答题”和“家长退出”供用户操作，但**手动点通知或返回 App 后出现题目，不算自动后台拦截通过**。
- 诊断新增主界面前后台、屏幕/锁屏状态、窗口可见回调、后台页面请求时间/显示时间及来源、家长页暂停/停止事件和真实安装版本。不收集小红书内容，不记录密码、题目或答案。
- 原生服务使用默认显示屏独立窗口上下文创建 `TYPE_APPLICATION_OVERLAY`，不跟随主 Activity 小窗尺寸。到期计时由原生服务负责，不依赖网页在前台；配置变化只调整题目宽度，不销毁窗口或清空答案。
- 家长退出使用独立、不对外导出的原生 Activity。等待该页 `onResume` 后才暂时撤掉答题浮层；守护仍为 active/locked。返回、取消或离开家长页恢复浮层，不会停止守护。只有正确密码才停止。
- 原生密码输入不写入磁盘、日志或实例保存状态；声明处理旋转、键盘与分屏配置变化，保留同一个输入控件。密码页禁止截屏、自动填充；验证失败保留页面，共享五次输错后的 30 秒限流。
- 服务启动需确认会话与心跳，不能只凭保存配置显示成功。设置页显示实际服务心跳、浮层挂载尺寸、通知与电池状态；异常不再标为“守护运行中”。
- 保留 `START_STICKY` 恢复机制与原到期时间；增加不申请精确闹钟权限的非精确唤醒提醒。若到期时服务已被停止，仅发通知与诊断，**不强行后台打开页面、不假装仍有遮罩**。回到应用后由家长点击恢复，保留原到期时间与进度。

## 在平板上验收（建议 1 分钟 / 答对 3 题）

| 操作 | 预期 |
|---|---|
| 在家长设置确认“安装版本 1.2”，设置 1 分钟；开启学习守护，按 Home 去看小红书，不点通知、不返回 App | 到期应自动出现题目浮层或原生答题页；否则此次后台验收失败，需要导出诊断 |
| 从小窗/分屏开启，再切换应用 | 题目浮层按显示屏布局，而非仅覆盖原应用小窗；系统栏仍可使用 |
| 进入浮层点“家长退出” | 原生密码页稳定显示，不自动消失；通知中的“家长退出”也可作为系统阻拦时的入口 |
| 点密码输入区域，再用页面内数字键盘输入三位并旋转平板 | 不应出现系统输入法；同一个密码页和输入仍在，页面不被遮罩盖回 |
| 输错密码 | 页面保留、提示错误；不停止守护 |
| 点“取消，返回答题”或系统返回键 | 浮层恢复，已答对题数保留；不是无密码退出 |
| 输入正确密码 | 浮层与守护通知结束，状态变为未开启 |
| 到期前息屏，超过到期时间后解锁 | 原到期时间保留，解锁后出现题目，不覆盖系统锁屏 |
| 划掉主界面最近任务 | 原生服务应继续；若厂商回收，设置页必须显示中断，不能误报成功 |
| 手动强制停止/撤销权限/重启 | 不承诺继续拦截；重新打开应用检查并恢复或重新开启 |

若仍不能后台弹题：停止测试，由家长进入“家长设置 → 设备与权限 → 导出运行诊断”，提供该 JSON、平板型号、系统版本及操作步骤。导出对象明确排除密码、密码哈希、题目、答案与孩子答题记录；不必卸载重装排查。

## 如何判断诊断

- `main_background` 后有持续心跳、`deadline_locked`：原生服务确实走到了到期分支；如果返回前没有到期记录且心跳中断，需要进一步检查后台冻结/回收，不能只归咎于浮层。
- `overlay_created`：只证明窗口已挂载；`quiz_window_visibility` 的 `visibility=0` 也只是框架报告可见，不证明厂商窗口合成器实际让用户看见。
- `quiz_activity_requested` 后有 `quiz_activity_not_confirmed`：后台原生页未确认进入前台。需核查后台弹出权限/系统启动策略；请求可能被静默阻止。
- `quiz_activity_resumed` 来源是“用户点击通知”：不能作为自动后台拦截证据。
- 家长数字键盘期间有 `parent_paused` 但没有 `parent_stopped_view`：应保持密码页接管，不能重挂遮罩。若实际仍消失，下一步必须连接真机检查窗口/Activity 日志。

## 验证边界

JVM 原生回归可验证服务/Activity 状态和配置变化，但不是实际输入法、系统后台策略或荣耀窗口合成器的设备验证。浮层“已挂载”不证明系统未隐藏或遮挡它。Doze 下非精确提醒可能延后；强制停止会取消系统提醒。普通安卓 App 不是不可绕过的系统锁屏，不禁止紧急功能、通知栏、系统设置或卸载。

1.2 本机验证：36 网页单测、29 安卓 JVM 测试（25 生命周期/界面交接、3 策略、1 模板）、9 三端关键浏览器回归通过。新增测试覆盖暂停但不停止、固定键盘删除/长度/验证、后台入口一次性请求/未确认告警、原生 Activity 与浮层的进度与交接。它们不是小红书真机拦截录像或验收。
