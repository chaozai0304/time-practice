# AI 开发历史教训与持续复盘

更新日期：2026-11-08。来源为本项目开发、浏览器/JVM 检查、已授权时的荣耀诊断和 GitHub 发布历史。这里只保存脱敏复盘。唯一完整规则：[AGENTS.md](../AGENTS.md)；[CLAUDE.md](../CLAUDE.md) 仅导入该正文。

## AI-001：把局部验证误当作真机完成

- **现象**：网页、编译、JVM 测试通过后生成“修复包”，用户在其他 App 使用时仍复现后台/密码页问题。
- **证据/原因**：测试只覆盖应用内或模拟环境；不能确认厂商窗口与后台策略。部分完成表述强于证据。
- **措施**：明确配置、编译、单测、网页、JVM、实际渲染、真机和远端发布各自的证明范围。
- **防复发/状态**：修改须附验收矩阵，报告未执行部分；当前后台可靠性与强防退出未通过验收，不能记为已解决。关联 `AGENTS.md` §3–4、`docs/DELIVERY.md`。

## AI-002：普通守护抵挡不了系统强停

- **现象**：荣耀最近任务上滑清理后守护失效，保存的开启标记仍存在。
- **已确认事实**：获得授权时的退出记录显示系统管家触发 `USER REQUESTED / FORCE STOP`，进程与服务不存在；悬浮窗和前台服务权限允许。仅确认该强停事件，不断言所有后台显示问题都同源。
- **措施**：区分移除 Activity、任务、进程回收/冻结和强停；不再凭 `active` 标记、`START_STICKY` 或 `stopWithTask=false` 保证运行。
- **防复发/状态**：检查真实心跳/显示证据；禁止用重装或重启定时器宣称防退出。Device Owner/DPC 方案尚未开发、激活；必须另行授权。关联 `GuardService.java`、`LearningGuardPlugin.java`、`docs/ANDROID_HONOR.md`。

## AI-003：家长输入页与遮罩生命周期竞争

- **现象**：家长密码页打开或系统键盘出现后被盖回/消失；配置变化曾重建输入控件。
- **证据等级**：源码确认 `onPause` 即恢复浮层、重建窗口存在风险；无完整 IME 真机轨迹时，不认定这是唯一根因。
- **措施**：独立原生验证页、页面内数字键盘；临时暂停/焦点丢失不当作不可见，配置调整保留控件与草稿；真正停止/取消才恢复界面。
- **防复发/状态**：新增暂停但不停止、键盘长度/删除/验证、旋转、界面交接、取消、限流与进度回归。JVM 通过不等于实际输入法已验收。关联 `ParentAccessActivity.java`、`GuardLifecycleTest.java`。

## AI-004：有 Canvas/按钮不等于可见或可点击

- **现象**：曾按 GPU 能力过早标记 3D；透明正文层遮挡背景内暂停按钮，手机正常点击失败。
- **证据/措施**：检查真实渲染与失败回退；暂停控制移至独立前景层，保留家长入口，按真实视口调整。
- **防复发/状态**：视觉复查非空画面、全屏边界和文字；`elementFromPoint` 命中 + 正常 click，不能 `force` 穿透。相关专项已通过，未来结构变更须重测。关联 `GuardPortal.tsx`、`guard-portal.spec.ts`、`guard-portal.css`。
- **2026-11-07 窄屏扩展**：手机编辑保存/词表导入/设置保存出现兄弟元素截获触点；截图及样式确认新多科目、多操作按钮的 nowrap 和表格列最小内容宽度撑出视口。修正科目与操作栏换行、`minmax(0,1fr)`/手机单列和控件最小宽度，新增页与弹窗无横向溢出断言，保留真实点击。复测结果见 `DELIVERY.md`。

## AI-005：截图脚本里的异步与表单定位错误

- **现象**：独立脚本默认 5 秒断言停在启动页；Toast 可见检查后点击时已自动消失；隐式 textarea label 曾干扰字段匹配。
- **措施**：按实际加载等待真实目标状态；Toast 等自然消失；显式 label/id；兼容随机选择/填空题，不按控件序号猜字段。
- **防复发/状态**：`docs:screenshots` 完整采集、实际演示记录、截图内容复查及 `docs:verify`；家长设置图必须包含保存按钮。9 张图片已在隔离网页采集，不是原生后台拦截证据。关联 `scripts/capture-docs.mjs`、`QuestionEditor.tsx`。
- **2026-11-07 扩展回归**：浏览器 `getByLabel(..., exact:true)` 在年级/题型下拉框等待超时，ARIA 可读名称存在不代表标签文本匹配；隐式 label 包含选项文字。将三个 select 同样改为独立 `label htmlFor`/`id`，保留精确定位与正常操作，不放宽断言或增加等待时间。专题结果见 `DELIVERY.md`。
- **2026-11-08 计时入口**：独立脚本默认断言 5 秒，在正常初始化页误报；改为与项目已有 20 秒一致并采集资源/长任务，不修改正式回归超时，不把首次失败当作应用已坏或性能改善证据。

## AI-006：本机命令和架构使验证失真

- **现象**：复用 cwd、长多行命令损坏、把 Shell 脚本交给 Python、Rosetta Chrome 超时、启动新同步命令中断仍在运行的构建。
- **措施**：明确 cwd/`git -C`、短命令或工具写脚本、Bash 执行、现有 ARM Chrome wrapper；检查运行/交互状态再继续。
- **防复发/状态**：不反复重发长输入、不 `sleep`/轮询、不盲改全局环境；核对退出码与真实输出。问题不是仅以等待时间变长解决。关联 `scripts/chrome-arm64.sh`、`scripts/verify-docs.mjs`。
- **2026-11-08 已确认复现**：ARM Mac 上 x64 Node 内的 `uname -m` 漏检硬件 ARM，原生 Chrome wrapper 未选中。两轮旧计时：启动3.528秒、初始化9.642/10.310秒、PBKDF2仅39/43毫秒、动作合计55.586秒；资源几十毫秒，主线程有秒级长任务。
- **修复/验证**：共享 `scripts/browser-platform.mjs` 查询 `hw.optional.arm64`，统一测试/截图/计时选择原生启动器，不换全局环境、不加worker、不降密码强度、不删断言。相同动作合计3.132秒，启动0.289秒、热初始化0.054秒；54项全量从约33.7分钟降至1.5分钟，66单测通过。新增ARM/Intel/非macOS/查询失败回归；仅本机证据，未操作设备，APK未变。
- 单独重跑Gradle绕过打包脚本时，漏掉子进程内设置的SDK环境，报告SDK location not found。先核对脚本默认路径，再仅本命令设 `ANDROID_HOME` 和隔离缓存重跑；不改全局配置。1.5最后43项JVM与123任务明确重跑通过。

## AI-007：发布网络、权限与成功状态混淆

- **现象**：GitHub 出现 HTTP/2、空响应及 443 超时；本地 commit 已创建但最初未推送，主页缓存仍显示空仓库。
- **措施**：分层检查网络/握手/授权，只检查凭据是否存在且不显示秘密；使用单次 HTTP/1.1/缓冲设置，不改全局代理。
- **防复发/状态**：推送后以公开 API 对比远端分支 SHA 和图片 blob SHA。初始发布已确认成功；不据缓存或本地提交推断远端结果，CI 必须单独核验。关联 `README.md`、`scripts/verify-docs.mjs`。

## AI-008：工程、归档、安装包和版本不等价

- **现象**：Android 最低版本需依据密码算法 API；iOS 有工程但平台组件/签名阻塞；同名 APK 易误装旧版本。
- **措施**：Android min API 26、实际版本/签名/hash 核验、明确版本文件名；iOS 编译/归档/分发分别说明。
- **防复发/状态**：交付副本与构建文件/文档一致，同签名覆盖更新，不卸载清数据；没有真实 IPA 就标记未生成。关联 `scripts/build-android.sh`、`docs/DELIVERY.md`、`docs/IOS_SETUP.md`。

## AI-009：规则文件与权限都不能靠假设生效

- **现象**：文件名、链接存在或曾经获得设备授权容易被误认为当前已读取规则/获准继续操作。
- **措施**：完整规则只存 `AGENTS.md`，Claude 用导入引用；默认禁止设备访问与未授权子智能体，不修改客户端全局设置。
- **本次修正**：原计划同时增加 Copilot 和标准入口，查阅规范后改为一个 `AGENTS.md` 入口；阅读复核时修正完成门禁的重复用词，没有让错误表述进入发布。
- **2026-11-08 用户调整**：旧入口与独立正文增加维护/读取负担；按要求合并并删除非标准正文文件。保留全部权限、安全、验证、复盘要求，校验脚本确认唯一正文、Claude 导入和所有链接，不用两份复制文件假装跨客户端兼容。
- **2026-11-08 补丁核对**：多文件补丁使用文档行的前缀而非实际完整段落，匹配失败；实查新增文件不存在、版本未改，确认未落盘后拆分重用完整上下文。没有依据失败调用宣称成功或重复覆盖已改文件。
- 同日性能文档更新再次触发上下文/片段顺序校验：先确认未落盘，再按文件拆分、按原文顺序提交片段；不凭失败回执假定部分成功。
- **防复发/状态**：`docs:verify` 检查规则单一来源、文档链接与 MIT 元数据；新会话仍需验发现/读取/遵守，不能保证永远强制生效。关联 `AGENTS.md`、`CLAUDE.md`、`scripts/verify-docs.mjs`。

## AI-010：学段与题型扩展后，旧断言和测试解题器过时（2026-11-07）

- **现象/证据**：首轮 Vitest 4 项失败，旧断言仍限定 120 题、把 7/9 年级视为无效；旧浏览器解题代码假定所有数学题都是两个数相乘。
- **已确认原因/措施**：产品边界已扩至 12 年级和三题型；改为校验全部年级科目、三题型及真假判断、真实无效边界 13，不删除核心安全断言。隔离浏览器从当前 fixture 的权威题目读取答案，不再按题干数字猜解法。
- **补充发现**：游戏逻辑提取后遗留一个未使用的 `Question` 类型导入，TypeScript 使浏览器预览服务无法启动；直接构建定位 TS6196 并移除，不调整超时掩盖失败。
- **防复发/状态**：增加三题型模板、词表、加权排序、近期降权、停用、游戏正误判分、非空/满容量旧数据迁移及三端交互回归；最终结果见 `DELIVERY.md`。测试证据不等于教材/真机验证。
- **关联**：`tests/unit/learning-expansion.test.ts`、`tests/unit/storage.test.ts`、`tests/e2e/learning-expansion.spec.ts`、`src/components/WordRunner.tsx`。

## AI-012：装饰动画不能冒充射击玩法（2026-11-08）

- **用户反馈/源码证据**：旧游戏中文在动画下方，答对只加分、重置装饰陨石，没有目标、弹道与碰撞；上一版验收只证明拼写反馈，不证明射击玩法满足要求。
- **措施**：重做全屏场景，中文作为可锁定目标真实下落；正确英文生成追踪子弹，命中才消除计分；加入出现间隔和下落速度、暂停/后台停止、漏词/真实尝试记录及10次命中休息。
- **测试暴露并修正**：首次状态机2项失败，改变生成频率仍沿用旧deadline；保存上一次间隔并按最近生成时间重算，保持原断言。测试继续覆盖弹道移动、碰撞、重复射击、漏词和参数行为，不用装饰元素数量代替真实命中。
- **验证/缺口**：最终结果见 `DELIVERY.md`；电脑视觉与浏览器/JVM不替代目标设备、后台或音频验收。关联 `src/lib/game.ts`、`src/components/WordRunner.tsx`、`tests/unit/word-shooter.test.ts`。
- 1.5最终：77单测、60三端全量E2E、43JVM通过。游戏截图在RAF启动前安装可控时钟，先断言子弹transform变化再暂停，避免将发射光点误当飞行帧；集成预览后台状态按要求暂停，不改visibility造证据。

## 每次犯错后的记录模板（无需等用户提醒）

在 `AGENTS.md` §11 流程内使用。相同根因更新已有编号，新根因才新增；删除占位说明后提交，不伪造日期或证据。

- **编号 / 日期**：稳定 `AI-xxx` 编号与实际记录日期。
- **现象 / 场景**：复现条件、期望和实际结果。
- **证据等级**：工具结果 / 源码风险 / JVM / 网页 / 真实渲染 / 已授权真机 / 远端验证；没有则写未确认。
- **根因状态**：已确认原因，或列出尚未验证的假设与阻塞。
- **修正措施**：实际改动、纠正的错误表述；未采取动作也要如实写。
- **防复发检查**：对应测试/断言/产物或权限门禁，不只写“注意”。
- **验证结果 / 未解决事项**：实际通过/失败/跳过与范围，不写过度完成声明。
- **关联路径 / 规则更新**：代码、测试、文档及是否需更新通用规则。

不要复制密码、令牌、密码哈希、孩子资料、设备序列号、个人目录和原始设备日志。暂时无法验证则保留未解决状态；不能为完成复盘去重新访问被禁止的设备。
