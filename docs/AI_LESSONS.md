# AI 开发历史教训与持续复盘

总结日期：2026-11-07。来源为本项目开发、浏览器/JVM 检查、已授权时的荣耀诊断和 GitHub 发布历史。这里保存**脱敏、可执行**的复盘，不保存真实设备/个人日志。规则入口：[AGENTS.md](../AGENTS.md)，完整规范：[Agent.md](../Agent.md)。

## AI-001：把局部验证误当作真机完成

- **现象**：网页、编译、JVM 测试通过后生成“修复包”，用户在其他 App 使用时仍复现后台/密码页问题。
- **证据/原因**：测试只覆盖应用内或模拟环境；不能确认厂商窗口与后台策略。部分完成表述强于证据。
- **措施**：明确配置、编译、单测、网页、JVM、实际渲染、真机和远端发布各自的证明范围。
- **防复发/状态**：修改须附验收矩阵，报告未执行部分；当前后台可靠性与强防退出未通过验收，不能记为已解决。关联 `Agent.md` §3–4、`docs/DELIVERY.md`。

## AI-002：普通守护抵挡不了系统强停

- **现象**：荣耀最近任务上滑清理后守护失效，保存的开启标记仍存在。
- **已确认事实**：获得授权时的退出记录显示系统管家触发 `USER REQUESTED / FORCE STOP`，进程与服务不存在；悬浮窗和前台服务权限允许。仅确认该强停事件，不断言所有后台显示问题都同源。
- **措施**：区分移除 Activity、任务、进程回收/冻结和强停；不再凭 `active` 标记、`START_STICKY` 或 `stopWithTask=false` 保证运行。
- **防复发/状态**：检查真实心跳/显示证据；禁止用重装或重启定时器宣称防退出。Device Owner/DPC 方案尚未开发、激活；必须另行授权。关联 `GuardService.java`、`LearningGuardPlugin.java`、`docs/ANDROID_HONOR.md`。

## AI-003：家长输入页与遮罩生命周期竞争

- **现象**：家长密码页打开或系统键盘出现后被盖回/消失；配置变化曾重建输入控件。
- **证据等级**：源码确认 `onPause` 即恢复浮层、重建窗口存在风险；无完整 IME 真机轨迹时，不认定这是唯一根因。
- **措施**：独立原生验证页、页面内数字键盘；临时暂停/焦点丢失不当作不可见，配置调整保留控件与草稿；真正停止/取消才恢复界面。
- **防复发/状态**：新增暂停但不停止、键盘长度/删除/验证、旋转、界面交接、取消、限流与进度回归。JVM 通过不等于实际输入法已验收。关联 `ParentAccessActivity.java`、`GuardLifecycleTest.java`。

## AI-004：有 Canvas/按钮不等于可见或可点击

- **现象**：曾按 GPU 能力过早标记 3D；透明正文层遮挡背景内暂停按钮，手机正常点击失败。
- **证据/措施**：检查真实渲染与失败回退；暂停控制移至独立前景层，保留家长入口，按真实视口调整。
- **防复发/状态**：视觉复查非空画面、全屏边界和文字；`elementFromPoint` 命中 + 正常 click，不能 `force` 穿透。相关专项已通过，未来结构变更须重测。关联 `GuardPortal.tsx`、`guard-portal.spec.ts`、`guard-portal.css`。

## AI-005：截图脚本里的异步与表单定位错误

- **现象**：独立脚本默认 5 秒断言停在启动页；Toast 可见检查后点击时已自动消失；隐式 textarea label 曾干扰字段匹配。
- **措施**：按实际加载等待真实目标状态；Toast 等自然消失；显式 label/id；兼容随机选择/填空题，不按控件序号猜字段。
- **防复发/状态**：`docs:screenshots` 完整采集、实际演示记录、截图内容复查及 `docs:verify`；家长设置图必须包含保存按钮。9 张图片已在隔离网页采集，不是原生后台拦截证据。关联 `scripts/capture-docs.mjs`、`QuestionEditor.tsx`。

## AI-006：本机命令和架构使验证失真

- **现象**：复用 cwd、长多行命令损坏、把 Shell 脚本交给 Python、Rosetta Chrome 超时、启动新同步命令中断仍在运行的构建。
- **措施**：明确 cwd/`git -C`、短命令或工具写脚本、Bash 执行、现有 ARM Chrome wrapper；检查运行/交互状态再继续。
- **防复发/状态**：不反复重发长输入、不 `sleep`/轮询、不盲改全局环境；核对退出码与真实输出。问题不是仅以等待时间变长解决。关联 `scripts/chrome-arm64.sh`、`scripts/verify-docs.mjs`。

## AI-007：发布网络、权限与成功状态混淆

- **现象**：GitHub 出现 HTTP/2、空响应及 443 超时；本地 commit 已创建但最初未推送，主页缓存仍显示空仓库。
- **措施**：分层检查网络/握手/授权，只检查凭据是否存在且不显示秘密；使用单次 HTTP/1.1/缓冲设置，不改全局代理。
- **防复发/状态**：推送后以公开 API 对比远端分支 SHA 和图片 blob SHA。初始发布已确认成功；不据缓存或本地提交推断远端结果，CI 必须单独核验。关联 `README.md`、`scripts/verify-docs.mjs`。

## AI-008：工程、归档、安装包和版本不等价

- **现象**：Android 最低版本需依据密码算法 API；iOS 有工程但平台组件/签名阻塞；同名 APK 易误装旧版本。
- **措施**：Android min API 26、实际版本/签名/hash 核验、明确版本文件名；iOS 编译/归档/分发分别说明。
- **防复发/状态**：交付副本与构建文件/文档一致，同签名覆盖更新，不卸载清数据；没有真实 IPA 就标记未生成。关联 `scripts/build-android.sh`、`docs/DELIVERY.md`、`docs/IOS_SETUP.md`。

## AI-009：规则文件与权限都不能靠假设生效

- **现象**：文件名、链接存在或曾经获得设备授权容易被误认为当前已读取规则/获准继续操作。
- **措施**：只设标准 `AGENTS.md` 自动入口，明确要求读取 `Agent.md`；默认禁止设备访问和未授权子智能体。不擅自修改客户端全局设置。
- **本次修正**：原计划同时增加 Copilot 和标准入口，查阅规范后改为一个 `AGENTS.md` 入口；阅读复核时修正完成门禁的重复用词，没有让错误表述进入发布。
- **防复发/状态**：`docs:verify` 检查精确文件名、入口指向、文档链接与 MIT 元数据；新会话仍须检查发现、包含与行为遵守三层。不能宣称规则文件永远强制生效；授权按最新范围核对，不随任务自动扩展。关联 `AGENTS.md`、`Agent.md`、`scripts/verify-docs.mjs`。

## 每次犯错后的记录模板（无需等用户提醒）

在 `Agent.md` §11 流程内使用。相同根因更新已有编号，新根因才新增；删除占位说明后提交，不伪造日期或证据。

- **编号 / 日期**：稳定 `AI-xxx` 编号与实际记录日期。
- **现象 / 场景**：复现条件、期望和实际结果。
- **证据等级**：工具结果 / 源码风险 / JVM / 网页 / 真实渲染 / 已授权真机 / 远端验证；没有则写未确认。
- **根因状态**：已确认原因，或列出尚未验证的假设与阻塞。
- **修正措施**：实际改动、纠正的错误表述；未采取动作也要如实写。
- **防复发检查**：对应测试/断言/产物或权限门禁，不只写“注意”。
- **验证结果 / 未解决事项**：实际通过/失败/跳过与范围，不写过度完成声明。
- **关联路径 / 规则更新**：代码、测试、文档及是否需更新通用规则。

不要复制密码、令牌、密码哈希、孩子资料、设备序列号、个人目录和原始设备日志。暂时无法验证则保留未解决状态；不能为完成复盘去重新访问被禁止的设备。
