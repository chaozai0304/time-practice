# 学伴时光 · Learning Island

## 来源与适配
- 使用本地 `.github/prompts/ui-ux-pro-max.prompt.md` 与搜索数据，查询 `children education playful learning app`。
- 采纳已核实的 Claymorphism / Soft 3D 风格、触控尺寸、对比度、暂停和减少动态效果规则。
- 检索中的 B2B 销售落地页结构不适用本产品，已排除；英文 Google 字体建议不适合离线中文，使用系统中文字体。

## 视觉
- 核心主题：孩子的学习小岛。雾蓝背景、紫蓝主按钮、薄荷绿成长反馈、暖黄奖励。
- 前景 #172344，次要文字 #53617b，主色 #6355d9，卡片 #ffffff，背景 #f4f6fd。
- 圆角 20–28px，柔和外阴影与细边框；同层级统一 Phosphor 线性图标。
- 中文系统字体，正文 14–16px；数据、标题层次明确。不用低对比浅灰小字承载规则。
- 手机操作区域至少 48×48px，4/8px 间距节奏，安全区和底部导航留白。

## 动画
- Remotion + Three.js + React Three Fiber，主场景为小岛、书本、嫩芽与绕行星球。
- 所有场景运动由 `useCurrentFrame()` 驱动，不用独立 useFrame 或 CSS 动画混入时间轴。
- 首页小岛与答题页宇宙分别使用自己的场景；提供暂停、键盘按钮以及视口外/后台暂停。答题页优先遵循 `pages/quiz.md`。
- prefers-reduced-motion、WebGL2 不支持或上下文丢失时使用本地静态矢量图，业务不受影响。
- 每个页面最多一个 WebGL 场景，像素比 1；不依赖在线模型、贴图和字体。
- 答题正确给非阻塞的短暂奖励，答错保持温和、无惩罚，不用动画拖延解锁。

## 不变规则
离线题库和密码逻辑不变；动画绝不能遮挡家长退出、确认答案或计时规则。安卓/iOS 原生权限和签名边界不因动画改变。
